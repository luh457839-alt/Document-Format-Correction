## 当前统一判定

以下情况可视为“通过型真实链路”：

- 成功产出 `output_docx_path`。
- 关键阶段已按预期执行，例如 `write_tool`、`reconcile`、`materialize`。
- 未出现 provider `reasoning_content` 回放兼容性错误。
- 在真实模型 smoke / regression 场景下，即使没有 `output_docx_path`，只要返回当前白名单内的结构化失败，也应视为“受控失败”，而不是阻塞回归：
  - `E_GRAPH_RECURSION_LIMIT`
  - `provider_read_loop_exhausted`
  - `provider_tool_args_unmappable`
  - `set_settings_flag requires explicit settings patch targets`
  - `set_settings_flag requires settings`

以下情况视为阻塞型失败：

- 无 `output_docx_path`，且不属于当前白名单内的结构化失败。
- graph 中断，或未进入应到达的关键阶段。
- 再次出现 `The reasoning_content in the thinking mode must be passed back to the API` 类错误。
- 返回了既不产出文档、也不落在当前白名单内的非结构化失败。
- 已知现象升级为用户可见错误，导致最终文档不正确或请求无法完成。
