# 样式与编号差异样本

## 文档用途或场景
用于验证多种段落样式、字符样式和编号级别差异在写回后的保真度。

## 是否可脱敏后长期保留在测试资源中
可长期保留。当前内容为人工构造样本，不含敏感信息。

## 关键结构点
- 是否有标题：有，一级标题和二级标题
- 是否有图片：无
- 是否有超链接：无
- 是否有页眉页脚：无
- 是否有表格：无
- 是否有脚注尾注：无
- 是否有多节：无
- 是否有特殊 styles / numbering / settings：有 `Intense Quote`、字符加粗/斜体/字号/颜色差异、`List Number`、`List Number 2`、`List Bullet`

## 期望验证内容
验证段落样式写入、字符级样式写入和编号层级写入是否符合预期，重点覆盖 `set_style_definition`、`set_numbering_level` 一类场景。

## 高风险目标
- 二级标题段落
- 引用段落“这是一个引用段落。”
- 含红色粗斜体文本的字符级 run
- 编号段落和二级编号段落
