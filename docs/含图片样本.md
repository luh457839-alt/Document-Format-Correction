# 含图片样本

## 文档用途或场景
用于验证正文图片、图片关系引用和图注在写回后的完整性。

## 是否可脱敏后长期保留在测试资源中
当前版本使用本地真实图片素材。仅在该图片已脱敏的前提下建议长期保留；若未脱敏，应替换为脱敏图后再纳入共享测试资源。

## 关键结构点
- 是否有标题：有，一级标题“含图片样本”
- 是否有图片：有，正文内嵌图片 1 张
- 是否有超链接：无
- 是否有页眉页脚：无
- 是否有表格：无
- 是否有脚注尾注：无
- 是否有多节：无
- 是否有特殊 styles / numbering / settings：有图注段落，居中对齐

## 期望验证内容
验证写后 `word/media` 引用、图片关系、文档包结构和图注段落不会损坏。

## 高风险目标
- 图片对象本身
- 图片关系引用
- 图注段落“图 1. 本地真实图片素材占位”
