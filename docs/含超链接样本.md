# 含超链接样本

## 文档用途或场景
用于验证正文外链样本，重点覆盖外部超链接和 `.rels` 关系写回边界。

## 是否可脱敏后长期保留在测试资源中
可长期保留。链接指向公开 IEEE PDF 资源，不含私密信息。

## 关键结构点
- 是否有标题：有，一级标题“含超链接样本”
- 是否有图片：无
- 是否有超链接：有，正文外链 1 个
- 是否有页眉页脚：无
- 是否有表格：无
- 是否有脚注尾注：无
- 是否有多节：无
- 是否有特殊 styles / numbering / settings：有底层 OXML 注入的 hyperlink 结构

## 期望验证内容
验证外链在写回后仍可正常解析，不会静默产出损坏包，也不会丢失关系定义。

## 高风险目标
- 超链接段落“请访问以下正文外链：”
- hyperlink 关系对象
- `document.xml.rels` 中对应的外链引用
