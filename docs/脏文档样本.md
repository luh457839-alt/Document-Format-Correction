# 脏文档样本

## 文档用途或场景
用于保留一组“视觉像标题、语义却退化”的异常输入，作为已知缺口和后续章节补齐资源。

## 是否可脱敏后长期保留在测试资源中
可长期保留。当前内容为人工构造样本，不含敏感信息。

## 关键结构点
- 是否有标题：视觉上有，但语义上无正式标题样式
- 是否有图片：无
- 是否有超链接：无
- 是否有页眉页脚：无
- 是否有表格：无
- 是否有脚注尾注：无
- 是否有多节：无
- 是否有特殊 styles / numbering / settings：有正文样式下的粗体大字号伪标题

## 期望验证内容
用于验证当前系统在 style_name、heading_level 缺失或退化时的识别边界，并为后续缺口修复保留稳定输入。

## 高风险目标
- 首段伪标题文本“这看起来像是一个大标题，但它只是正文样式。”
- 第二段对异常结构的解释文本
