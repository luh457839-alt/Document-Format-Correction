# 高风险复杂样本

## 文档用途或场景
用于验证多种高风险结构组合出现时，当前 reconcile 和写回链路是否仍能产出可打开、结构完整的文档。

## 是否可脱敏后长期保留在测试资源中
当前版本使用本地真实图片素材。仅在图片已脱敏时建议长期保留；若未脱敏，应替换图片后再纳入共享测试资源。

## 关键结构点
- 是否有标题：有，一级标题“高风险复杂样本”
- 是否有图片：有，正文内嵌图片 1 张
- 是否有超链接：有，正文链接 1 个，表格内链接 1 个
- 是否有页眉页脚：有
- 是否有表格：有，2 行 2 列表格
- 是否有脚注尾注：无原生脚注尾注，使用文本附注模拟脚注缺口
- 是否有多节：无
- 是否有特殊 styles / numbering / settings：有编号列表、表格内 hyperlink、真实图片引用、页眉页脚组合

## 期望验证内容
验证图片、超链接、表格、编号、页眉页脚组合存在时，写回链路不会破坏关系文件、表格结构、编号样式或文档包完整性。

## 高风险目标
- 正文超链接段落
- 正文图片对象
- 两个编号段落
- 表格对象，尤其是表格内超链接单元格
- 页眉“高风险样本 页眉占位”
- 页脚“高风险样本 页脚占位”
- 末尾附注段落“附注[1]：此处用文本模拟脚注缺口，便于后续边界分析。”
