# 标准正文样本

## 文档用途或场景
用于验证 DOCX 主链的基础闭环，覆盖标题、正文、列表、表格、页眉页脚等常见基础结构。

## 是否可脱敏后长期保留在测试资源中
可长期保留。当前内容为人工构造样本，不含敏感信息。

## 关键结构点
- 是否有标题：有，一级标题“标准正文样本”
- 是否有图片：无
- 是否有超链接：无
- 是否有页眉页脚：有
- 是否有表格：有，3 行 2 列表格
- 是否有脚注尾注：无
- 是否有多节：无
- 是否有特殊 styles / numbering / settings：有基础列表样式，包含 `List Bullet` 和 `List Number`

## 期望验证内容
验证基础段落、标题、列表、表格、页眉页脚同时存在时，读取、修改、写回和重新打开的主链稳定性。

## 高风险目标
- 一级标题段落
- 两个列表段落
- 表格对象及其单元格文本
- 首页页眉与页脚
