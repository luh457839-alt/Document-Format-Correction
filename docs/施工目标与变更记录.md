# 施工目标与变更记录

本文档用于记录本项目每次有意义的施工目标、实施方式和验证结果。所有实现、修复、重构、配置变更和工作流调整都应追加记录。

## 记录规则

- 开工前先追加一条记录，状态为 `planned`。
- 完成后更新同一条记录，状态改为 `completed`、`partial` 或 `blocked`。
- 保留历史，不删除旧记录；如需修正，追加“修正”说明。
- 验证命令必须写清命令、结果和未执行原因。

## 状态

- `planned`：已定义目标，尚未完成。
- `completed`：实现和验证均已完成。
- `partial`：部分完成，仍有后续项。
- `blocked`：受外部条件或决策阻塞。

## 记录模板

```markdown
### YYYY-MM-DD HH:mm - 标题

- 状态：planned | completed | partial | blocked
- 目标：
- 范围：
- 计划：
- 实现方式：
- 涉及文件：
- 验证：
- 结果：
- 遗留风险：
- 后续建议：
```
